# Sweetbrier Universal Verification Engine (UVE)

Welcome to the Harness module for the Sweetbrier Node. 

The Universal Verification Engine (UVE) is a structural, neurosymbolic verification loop designed to ensure absolute alignment and mitigate semantic hallucinations in localized language models. By utilizing a Directed Acyclic Graph (DAG) for constraint modeling and a NATS event bus for asynchronous verification, the UVE guarantees that generated outputs adhere strictly to user-defined sociological and technical parameters.

### Core Modules
* `oracle.py` / `grant_pipeline.py`: Enforces geometric constraint modeling to prevent corporate AI drift.
* `nats_bus_integration.py`: Simulates the asynchronous pub/sub verification loop between the Oracle and the local THOU-instance.
* `engine_passions.py`: Models thermodynamic constraint weighting for localized Bayesian alignment.
