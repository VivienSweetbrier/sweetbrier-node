# Fresh replication run — 25 November 2026

An independent re-run of this harness's 30-problem evaluation (`run_eval.py`),
executed 25 November 2026 on a clean checkout of this repository, comparing
the **unconstrained** condition against the **full** Sweetbrier condition.

## Setup

- Model: `qwen2.5-coder:1.5b`, served locally via Ollama
- Temperature 0, seed 42
- Analysis: this repository's own `analyze_results.py`, unmodified
- Raw outputs, in this directory:
  - `run_unconstrained_20261125T192627.jsonl`
  - `run_full_20261125T195014.jsonl`

## Results (analyzer output)

| Tier | Metric | Unconstrained | Full |
|------|--------|---------------|------|
| A | Code pass | 10.0% | **60.0%** |
| B | Violation rate | 10.0% | **0.0%** |

Constraint pass was 100% in both conditions. The single violation recorded
in the unconstrained run does not occur under the full condition. Tier B
code pass is 0% in both conditions: the 1.5B model failed those coding items
outright either way — the constraint layer neither caused nor cured that.

The Z3 axiom smoke test was also re-run the same day: a benign prompt
verifies True; a financial-extraction prompt verifies False.

## Caveats, in the open

One run, one seed, n = 10 per tier. The model is a 1.5B stand-in, far
smaller than the 8B-class local model of the recorded September 2026 runs
archived in this repository, so absolute levels are **not** comparable
across eras. What replicates is the direction and the mechanism: the full
condition removes the violation and multiplies Tier A code pass at no
measured cost on the control tiers. Reproduce it yourself — the harness,
the raw outputs, and the analyzer are all in this repo.
