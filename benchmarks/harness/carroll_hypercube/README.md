# Lewis Carroll Hypercube ($Q_n$) & REA Verification Suite 🌸

A dependency-free, Windows-native verification and quantitative simulation harness implementing **Charles Lutwidge Dodgson's (Lewis Carroll's) Biliteral & Triliteral Diagrams** as a sub-millisecond Boolean decision gate (`carroll_gate.py`).

---

## 1. Quickstart (Run in 5 Seconds on Windows / Linux / macOS)

```powershell
# 1. Run the Sovereign AI & Indic Constraint Benchmark (Sarvam-1 / Maimonidean Trellis)
python evaluate_sarvam.py

# 2. Run the Multi-Asset Cost-Aware Quantitative Timeline Simulation
python practice_mode.py

# 3. Print the Standalone SQLite Evidence Ledger Audit Card
python ledger_analytics.py
```
